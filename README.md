# 息见 · GitHub访问版

保留“击球／观察／抛球”、股息历史位置、参考线、历史检验、自选分组、持仓和到账记账。

GitHub Pages 不运行实时后端。本版本直接从浏览器查询允许的公开行情源；有来源限制时，明确使用带日期的公开数据快照。快照由 GitHub Actions 定期更新，超过72小时会暂停参考，不伪装成实时数据。

新访客首先看到欢迎页，须选择“游客体验”或“邮箱注册／登录”后才进入网站。选择前不渲染看板、持仓或导航，也不发起行情读取；直接打开内部链接同样需先选择。游客选择在当前标签页内保留，已有邮箱登录需服务端验证成功后自动进入；过期登录和退出回到欢迎页。协议与注册找回表单可直接在欢迎页查看。

游客的个人记录仅保存在当前浏览器。可从欢迎页或“我的→邮箱登录与同步”免费注册：邮箱作为未验证的登录名，密码登录，使用恢复码找回。登录后同步自选、分组、精选、持仓、交易、到账分红和偏好。不同设备同时修改时保留两份供选择，不静默覆盖。原私人网站的账号备份不会自动迁移。

账号后端使用现有Sites托管与账号隔离的D1，存储内容加密，不上传至公开仓库。无需另购服务器，不接入付费邮件；初始试用上限200账号、每份1.5MB，不承诺无限额度或永久可用。退出后本机记录保留，共用设备请清理。支持文件导出、云端删除和账号注销。问题反馈仍通过GitHub。

服务已部署。客户端115项测试与服务端4项安全/数据测试通过。独立GitHub运行环境已验证真实注册、登录、跨会话数据读写、账号隔离、冲突保护、恢复码和旧会话失效，并删除了临时账号。外部验证记录：https://github.com/hutaoswag96/xijian/actions/runs/42790116707 。这不等于验证了所有中国网络；连接失败时明确提示并保留本机记录。

## 构建

需要Node.js 24，无需安装第三方依赖。

```
node --test tests/*.test.mjs
node scripts/build-pages.mjs
node scripts/refresh-data.mjs
```

`docs/` 是静态发布目录；`github/watch-symbols.json` 只配置公开行情快照的代码，不是系统推荐，不含任何个人账本。配置外股票会尝试直接查询，源不可达时明确显示失败。

本地运行可使用任何静态HTTP服务打开docs/；不要直接双击file://网页，否则浏览器可能禁止模块导入。
